# Основная идея проекта

## Канонический источник

Идея ведётся в соседнем репозитории [`idea.box`](../../../idea.box/content/applications/quest-book.today/index.md),
в каталоге `content/applications/quest-book.today`. Этот файл — краткий проектный контекст;
оригинал в `idea.box` остаётся источником идеи.

## Описание

Идея описывает приложение по принципу author.today для квестовых книг и сторителлинга,
направленное на распространение и популяризацию этого формата. Координатор описывает продукт
как библиотеку игр по книгам в жанре QuestBook.

## Особенности идеи

- Соавторство: авторы могут расширять сюжетные линии друг друга; условия прав и оплаты
  предполагается задавать для отдельных частей.
- Ветвящиеся сюжеты: читатель/игрок проходит выбранные или автоматически подобранные ответвления.
- Персонализация образов героев и сцен с помощью генерации изображений ИИ.

Идея также рассматривает продажу книг и подписки на авторов. Эти положения — гипотезы из
исходной идеи, а не утверждённые требования или проверенные бизнес-решения.

## Связанные прототипы и источники

- Возможный источник книг и партнёр: [quest-book.ru](https://quest-book.ru).
- Мобильный прототип: этот Flutter-репозиторий.
- Прототипы: [AWS](https://github.com/apostol/questbook-aws) и
  [React](https://github.com/apostol/questbook-store-react).
