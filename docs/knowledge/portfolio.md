## Стадии

- **разработка** — задачи ведутся, завершение не подтверждено.
- **готов к выпуску** — все задачи закрыты, ворота QA и приёмка пройдены, план выпуска есть.
- **в продакшене** — выпуск подтверждён проверкой в продакшне.
- **анализ идей** — разработка завершена, идёт анализ продукта и проекта.
- **новый цикл ждёт разрешения** — идеи оформлены, человек ещё не разрешил новый цикл.
- **закрыт** — проект закрыт решением человека; причина названа в `decisions.md`.

## Правила

- Счётчик задач — `done/total` из записей; источник — `<tasks_dir>` и дата среза.
- Каждая запись принадлежит строке; запись, которую не к чему отнести, — пробел, а не «общий
  бэклог».
- Выпуск без версии, даты и проверки в продакшне не считается выпуском.
- Идея без карточки не считается оформленной.
- Новый цикл начинается только после явного разрешения человека; до этого строка остаётся
  «новый цикл ждёт разрешения».
- Строка без владельца и источника — пробел, а не факт.
- Внешний прототип без подтверждённого владельца и устава — не подпроект в работе, а неизвестная
  строка; задачи по нему не создаются до решения человека.
