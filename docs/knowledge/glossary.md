# Словарь: QuestBook.today

Один термин — одно значение. Синоним, взятый для красоты, стоит дороже, чем кажется: его
по-разному понимают человек, агент и тест.

| Термин | Значение | Не путать с | Источник |
|---|---|---|---|
| QuestBook | Библиотека игр по книгам в жанре квестовых книг и сторителлинга | Книжный магазин Flutter-прототипа; идея продукта шире текущего репозитория | `docs/context/project.md`; `docs/product.md` |
| Гость | Пользователь без регистрации, проходящий встроенную историю на одной установке | Зарегистрированный пользователь, автор, плательщик | User Story QUE-3; Epic QUE-1 |
| Первый технический срез | Гостевой вход в одну встроенную историю, ветвящиеся выборы, концовка и локальное сохранение/возобновление на той же установке; Android API 30 | Полный продукт, публичный запуск, синхронизация между устройствами | Epic QUE-1; Feature QUE-2; `docs/decisions/2026-11-22-nfr-and-target-platforms.md` |
| Встроенная тестовая история QUE-BUNDLED-001 | История «Книга, которую никто не открывал»: три фрагмента, одно ветвление с двумя вариантами, одна концовка с двумя вариантами текста; только текст | Пользовательский контент, несколько историй, иллюстрации, звук | `docs/decisions/2026-11-22-bundled-test-story-content.md` |
| Локальный прогресс | Сохранённое на устройстве состояние прохождения: «В процессе» или «Завершена», место в истории, сделанные выборы, признак совместимости | Аккаунт, облачная синхронизация, перенос между устройствами | User Story QUE-3; BA-задача QUE-4 |
| Концовка | Завершающий фрагмент истории; текст зависит от выбранной ветки | Промежуточный фрагмент; коллекция концовок; спойлер-контроль | `docs/decisions/2026-11-22-behavior-after-ending.md` |
| «Пройти заново» | Действие гостя, которое сбрасывает прогресс и начинает историю с узла start | Автоматический старт после концовки; повторное открытие без действия | `docs/decisions/2026-11-22-behavior-after-ending.md` |
| NFR | Нефункциональные требования первого среза: холодный старт, переход между фрагментами, сохранность, совместимость, offline, платформа | Продуктовая метрика; baseline; коммерческое обещание | `docs/artifacts/project/requirements.md`; `docs/decisions/2026-11-22-nfr-and-target-platforms.md` |
| REQ-QUE-001…006 | Численные NFR и ограничение платформы, зафиксированные владельцем требований для первого среза | FR-001/FR-002 в спецификации; ER-001 в Epic; продуктовая метрика | `docs/artifacts/project/requirements.md`; `worktree-ba-que-3:docs/artifacts/requirements` |
| YouGile | Трекер задач проекта QuestBook.today; доска и записи синхронизируются | Локальные записи в `.agai/tasks`; база знаний координатора | `.agai/config.json`; записи QUE-1…QUE-4 |
| Epic | Верхняя запись продукта: QUE-1 — гостевое прохождение интерактивной истории | Feature; User Story; Task | `.agai/tasks/bbcd25c4-7c97-49f2-a7ef-ac6cb5f93be3/task.md` |
| Feature | Функциональная часть Epic: QUE-2 — гостевое прохождение тестовой истории и локальное продолжение | User Story; компонент; задача разработки | `.agai/tasks/c96738a6-c75b-46c5-bcbf-4453a97c389e/task.md` |
| User Story | Пользовательская история: QUE-3 — гость проходит тестовую историю и продолжает её на том же устройстве | Feature; задача QA; техническая задача | `.agai/tasks/432a7eda-1ca8-4289-9491-e50dd8939ec5/task.md` |
